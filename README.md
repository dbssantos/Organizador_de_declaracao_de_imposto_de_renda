# 📁 Organizador de Imposto de Renda — Excel

## 📌 Sobre o projeto

Este projeto é uma planilha desenvolvida no **Microsoft Excel** para organizar informações e documentos que podem ser necessários durante a preparação da declaração do Imposto de Renda.

A proposta é reunir dados do titular, informes de rendimentos bancários e registros de entradas financeiras em uma estrutura visual organizada, facilitando o preenchimento e a conferência das informações.

Este é um projeto de aprendizagem desenvolvido durante uma atividade da DIO.

## 🎯 Objetivos

- Praticar a organização de dados em planilhas;
- Explorar diferentes formatos de células e informações;
- Estruturar campos para facilitar o preenchimento;
- Reunir informações em abas separadas por categoria;
- Utilizar a função SOMA para consolidar valores.

## 🗂️ Estrutura da planilha

O arquivo está organizado nas seguintes abas:

### 1. `TITULAR`

Área destinada ao cadastro das informações do titular, como nome, CPF, data de nascimento, endereço e outros dados cadastrais.

### 2. `INFORMES`

Área para registrar informações de rendimentos bancários, incluindo instituição financeira, valor informado e nome do documento anexado. A aba também apresenta um campo de totalização dos valores.

### 3. `NOTAS`

Área para registrar entradas financeiras, com campos como data, categoria e valor.

### 4. `Planilha4`

Lista de instituições bancárias utilizada como base de referência para o preenchimento.

## 🛠️ Recursos utilizados

- **Microsoft Excel**;
- Função `SOMA` para totalizar valores;
- Formatação de células e campos;
- Organização das informações em diferentes abas;
- Estruturação de tabelas para facilitar a leitura e o preenchimento;
- Listas de referência para padronizar informações.

## 🧠 Principais aprendizados

Embora a planilha utilize uma fórmula simples, o desenvolvimento permitiu praticar habilidades importantes, como:

- Escolher formatos adequados para diferentes tipos de dados;
- Organizar informações de maneira clara;
- Separar os dados por finalidade;
- Melhorar a apresentação visual e a legibilidade da planilha;
- Pensar na experiência de quem precisa preencher e consultar as informações.

## ⚠️ Observação importante

Esta planilha é um **exercício de organização e aprendizagem**, não um sistema oficial de declaração de Imposto de Renda nem uma ferramenta de orientação tributária. Ela não substitui as instruções da Receita Federal ou o acompanhamento de um profissional qualificado.

Os dados pessoais e financeiros do exemplo são ficticios. Não compartilhe CPF, endereço, telefone, e-mail ou documentos reais.
